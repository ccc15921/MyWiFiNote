Wi-Fi Sensing（IEEE 802.11bf）
WLAN Sensing 導讀與速查

802.11bf 讓 Wi-Fi 在通訊之外，能用既有的 PHY / MAC 做「感測」：從無線訊號的變化（CSI）推估物體的距離、速度與動作，用於存在偵測、動作偵測、手勢分類、呼吸量測等。本頁依 IEEE 802.11bf-2025 正式版整理，並以作者 2023 年的介紹簡報作為導讀主線。

1總覽

WLAN sensing 利用 802.11 的 PHY 與 MAC 功能做環境量測，估計物體的 range、velocity 與 motion（4.11，PDF p.27–28）。應用大致分三類（取自簡報）：Detection（二元分類，如有無人）、Recognition（多類別分類，如手勢）、Estimation（數值估計，如大小、長度、角度、距離）。

2程序全貌

一次 sensing procedure 由「能力交換 → 建立一或多個 measurement session → 每個 session 內執行一次以上 measurement exchange → 終止」組成（11.55.1.1，PDF p.136–137）。

  • Session 持續到被明確終止，或 session expiry timer 到期。
  • Initiator 可擔任 sensing transmitter、receiver、兩者，或兩者皆非；responder 至少是 transmitter 或 receiver 其中之一。
  • AP 發起時，已 association 的 non-AP STA 以 AID 識別，未 association 的以 USID 識別。
  • Annex AI 以 AP 對 STA A / B / C 的範例，示範 Session ID 與 Exchange ID 如何指派、重用與終止（PDF p.227）。

3角色

Sensing 有兩組正交的角色：誰發起（initiator / responder）與誰打 NDP、誰收 NDP（transmitter / receiver）。定義見 3.2（PDF p.25–26）。

角色定義一句話
Sensing initiator (SI)傳送 Sensing Measurement Request frame 發起 sensing procedure 的 HE / EHT STA發起的人
Sensing responder (SR)回應 initiator 並參與 sensing procedure 的 STA被邀請的人
Sensing transmitter傳送用於量測之 PPDU（NDP）的 STA打 NDP 的
Sensing receiver這些 PPDU 的目標接收者，並取得量測結果收 NDP 的、算 CSI 的
常見混淆：SI / SR 與 transmitter / receiver 不是同一件事。TB 交換中 AP 是 SI，但可以是 transmitter（NDPA sounding）也可以是 receiver（TF sounding）；non-TB 交換中 non-AP STA 是 SI、AP 是 SR。

4能力交換與 Session

4.1 支援 sensing 的前提

  • Sensing STA 須為 HE 或 EHT STA，dot11SensingImplemented = true，Extended Capabilities 的 Sensing field 設 1，且須同時支援 initiator 與 responder 兩種角色（11.55.1.2，PDF p.137–138）。
  • 每條 receive chain 的 RSSI 在 −82 至 −20 dBm 範圍需精確到 ±5 dB（95% 信賴區間）。

4.2 能力交換（11.55.1.3，PDF p.138–139）

  • Sensing Capabilities element（9.4.2.332）須出現在 Probe Response、(Re)Association Request / Response 與 Sensing Measurement Query frame；Probe Request 中可選。
  • 內容涵蓋：支援的最大頻寬、各頻寬最大 TX / RX 空間串流數、LTF 重複與總數、最大並行 session 數、最小量測間隔、是否需被 polling、threshold-based reporting、Ng = 16、SR2SR 支援、最大接收鏈數、「僅 20 MHz sensing transmitter」等（9 octets）。
  • AP 於 Probe Response 將 Responder Needed 設 1，表示需要新的 responder。
  • Non-AP STA 未 association 時，可傳 Sensing Measurement Query（攜帶其能力）請 AP 發起 session；Query 內須含 ISTA Availability Window element。

4.3 建立 session（11.55.1.4，PDF p.139–145）

  • Initiator 傳 Sensing Measurement Request，responder 回 Sensing Measurement Response（Status Code：SUCCESS、REJECTED_WITH_SUGGESTED_SENSING_PARAMETERS、REQUEST_DECLINED）。
  • Session 以 <initiator MAC address, Measurement Session ID> 識別；各 STA 的角色可為 sensing receiver、transmitter 或兩者，操作參數建立後固定不變。
  • Session 逾時 = 2(Measurement Session Expiry Exponent + 8) ms；有參與 exchange 就重設 timer。Request / Response 的回覆時限 aSensingFrameExchangeExpiry = 20 ms。
  • AP 發起時須帶 TB Sensing Specific subelement（AID / USID、Poll Assigned、CSI Variation Threshold、SR2SR、RSTA Availability Window）；non-AP 發起則帶 Non-TB Sensing Specific subelement（含 Min Measurement Interval）。
  • Availability window 的 Count 單位為 10 TU，須為 AP Beacon Interval（以 10 TU 計）的倍數。

4.4 Unassociated STA

未 association 的 non-AP STA 也能建立 session：直接傳含 Non-TB 子元素的 Request，或傳 Query 請 AP 發出 Request，並透過 Comeback 機制（aSensingComebackAfter / Before）與 USID 維持互動（11.55.1.4.2）。若 AP 要求 PMF，須先以 PASN 建立 PTKSA，否則 AP 會丟棄其 Request / Query。

4.5 終止（11.55.1.6）

任一方可隨時以 Sensing Measurement Termination frame 明確終止，只影響該對 STA；或於 session expiry timer 逾時後隱含終止。BSS 參數改變（如 TPE、disabled subchannel bitmap）時，AP 須明確終止與 unassociated STA 的 session。

5TB 量測交換（Trigger-Based）

適用於 AP 為 initiator、一或多個 non-AP STA 為 responder 的 session。由 polling → NDPA sounding → TF sounding → reporting 四個階段組成，各階段間隔 SIFS，且須在 sensing availability window 內進行（11.55.1.5.2，PDF p.146–158）。

TB exchange 不得僅含 reporting phase、僅 NDPA sounding、僅 SR2SR TF sounding（responder 為 receiver），或僅 polling + reporting。

6Non-TB 量測交換

適用於 non-AP STA 為 initiator、AP 為 responder 的 session：non-AP STA 只要媒體可用即可發起，頻率受 AP 的 Min Measurement Interval 限制（11.55.1.5.3，PDF p.158–161）。

  • 必含 measurement sounding phase；僅當 Sensing Measurement Report Requested = 1 才有 reporting phase。
  • NDPA 的 STA Info 含 AID11=0（SR2SI / SI2SR 的 NSTS 與重複數）與 AID11=2045（SI2SR NDP TX Power、SR2SI NDP RSSI Target）。
  • 只擔任 transmitter 或 receiver 時，可把另一方向的 NSTS 與 Rep 設 0 以縮短 NDP。
  • 報告內容可對應「前一次」exchange 的量測；此時首次 exchange 需設 Invalid Indication = 1。

7SBP（Sensing By Proxy）

SBP 讓 non-AP STA（SBP initiator）請 AP（SBP responder）代為執行 sensing，並把結果回報給自己（11.55.2，PDF p.165–173）。量測本身使用 TB sensing measurement exchange。

  • Setup：SBP Request（含 SBP Parameters 與 Sensing Measurement Parameters element）須在 aSBPSetupExpiry = 100 ms 內得到 SBP Response；Status Code 為 SUCCESS、REQUEST_DECLINED 或 REJECTED_WITH_SUGGESTED_SENSING_PARAMETERS。
  • 參數：可指定需要的 responder 數量（Number Of Sensing Responders）、是否強制（Mandatory Number Of Responders）、偏好的 responder 名單與角色 bitmap、是否要求 SR2SR sounding。
  • Reporting：AP 以 Sensing Measurement Report frame 回報；initiator 須出現在 AP 指派的 availability window 內才收得到。
  • Termination：initiator 可隨時以 SBP Termination frame 終止；終止後 AP 也會終止相關的 sensing session。
  • SBP procedure 的逾時時間由 SBP Procedure Expiry Exponent 決定，且應大於 Measurement Session Expiry Exponent。

8量測回報（CSI）

Sensing receiver 收到 NDP 後算出 CSI，經縮放與量化放入 Sensing Measurement Report frame 回報（9.4.1.81，PDF p.54–70；11.55.1.5.4，PDF p.161–163）。

編碼
  • 對每組 (receive chain r, transmit chain t, subcarrier k) 的 CSI H(r,t,k)，實部與虛部各量化為 8 bits 的 2s complement 整數。
  • Receiver 選一個正的 12-bit scaling factor 避免溢位（值由實作決定），接收端解碼後乘回還原。
  • Ng（subcarrier grouping）：Ng=4 或 8（≥5 chains 且 BW ≥160 MHz 為 8），或可選 Ng=16。
Report Control field 內容
  • BW、Nt、Nr、Ng、Rx_OP_Gain_Type、CSI Variation Feedback。
  • NDP 有 puncturing 時帶 Puncturing Pattern（16 bits）。
  • 要求時帶 Reference Timestamp（取 sensing receiver TSF[31:0]）。

8.1 Basic 與 threshold-based reporting

  • CSI Variation Threshold：0–10 表示 threshold-based reporting（以每 0.1 一級的 CSI variation 為門檻，只回報超過門檻者），15 表示 basic reporting（回報實際量測結果）。
  • Threshold-based 可讓 AP 先找出「CSI 變動夠大」的 responder，再決定要不要拉完整報告，降低回報的 airtime。

8.2 大報告的分段

CSI 超過 aSensingReportSegmentSize（3750 octets）時，最多切成 32 段，各放入獨立的 Sensing Measurement Report Container；僅第一段含 Report Control，並以 Remaining Report Segments 遞減順序、於單一 A-MPDU 內傳送。

8.3 Receiver 操作條件（11.55.1.5.5）

Receiver 的增益設定等會影響 CSI 估計，因此可在報告中帶 Rx_OP_Gain_Index（0–255，越大代表對 CSI 估計的影響越大，0 為可忽略）與 Rx_OP_Gain_Type（0 不回報、1 operating point index、2 gain index）。Type 2 時 index 拆成 RF / Analog Gain（0–63）與 Digital Gain（1–3）。

8.4 一致性規則

  • 同一 session 內 receiver / transmitter 須使用相同順序的 RF chain 與天線；無效 chain 的 CSI 設 0。
  • Transmit chain 不可用則不得傳該 NDP；全部不可用時 session 隱含終止。
  • 空間映射矩陣為 permutation（NSTS = NTX）或 permutation 加零矩陣（NSTS < NTX），串流到天線埠的映射在 session 內不變。

9DMG sensing（60 GHz）

802.11bf 同時定義 DMG STA（60 GHz）的 sensing 與 SBP，結構與 sub-7 GHz 類似，但以 burst 累積長時間量測，並有多種幾何配置（11.55.3、11.55.4，PDF p.173–202）。簡報未涵蓋此部分。

類型說明
MonostaticTransmitter 與 receiver 為同一個 STA
BistaticTransmitter 與 receiver 為兩個不同 STA
Multistatic一個 transmitter 與多個 receiver
Passive接收並非專為 sensing 傳送的 PPDU（如 DMG Beacon），取得 beacon 方向與 AP/PCP 位置資訊
Coordinated monostatic由 DMG AP/PCP 協調多個 monostatic responder
Coordinated bistatic一個 initiator 協調多個 responder
  • 程序階層：procedure → burst → measurement exchange；一個 exchange 限於單一 TXOP 或 SP，含 initiation、sounding、reporting 三個 phase（sounding 必選）。
  • Burst 機制讓 Doppler 等需長時間累積的量測不受單一 TXOP 限制，initiator 可要求每個 exchange 回報，或每個 burst 回報一次。
  • 相關新增 frame / element 包含 DMG Sensing Measurement Request / Response / Report / Termination、DMG SBP 系列，以及 DMG Sensing Report element（Image / Targets 兩種資料）。
